# Muestras para verificación manual

- `impreso.png`: texto impreso simulado en español e inglés (Arial).
- `manuscrito.png`: texto manuscrito simulado en español e inglés (Ink Free).

- `manuscrito-real.jpg`: manuscrito real en inglés (muestra de TrOCR).
- `impreso-real.png`: captura real de un párrafo en español (Wikipedia, recortada).
